## Features
- **Simple Mechanics**: Drag back and release to shoot.
- **Physics**: Projectile motion with gravity.
- **Moving Targets**: Test your aim against moving targets.
- **Score Tracking**: Keep track of your high score.

## How to Play
1. Open the Command Palette (`Cmd+Shift+P` or `Ctrl+Shift+P`).
2. Type `Start Archery Master`.
3. A new tab will open with the game.
4. Click near the bow, drag back to aim and power up, then release to shoot!

## Installation
Currently available via manual install or building from source.

## Requirements
VS Code 1.80.0 or higher.
